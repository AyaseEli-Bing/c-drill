# c-drill

C 语言语法刷题训练程序（终端交互，单个 `.c` 文件，零依赖）。

出题考查容易出错的语法点：整数除法与取模的截断方向、`char` 溢出、浮点比较、运算符优先级、`switch` 贯穿、短路求值、数组部分初始化、`strlen` 与 `sizeof`、指针退化、`static` 局部变量、宏的纯文本替换等。每道题答完立刻给判定和解析。

## 编译与运行

```sh
clang -std=c11 -Wall -Wextra -O2 cdrill.c -o cdrill
./cdrill
```

只用 C11 标准库（`stdio` / `stdlib` / `string` / `strings` / `ctype` / `errno` / `time` / `unistd`）。在 macOS / Linux 下可直接运行；Windows 上把 `#include <unistd.h>` 与 `isatty` 判断去掉即可（只影响颜色开关）。

## 功能

- 41 道题，7 个知识点：数据类型与运算、运算符与优先级、控制流、数组与字符串、指针与内存、函数与作用域、预处理
- 两种题型：选择题（接受 `A`-`D` 或 `1`-`4`，大小写均可）、读程序写结果（填整数）
- 五种模式：顺序全刷、随机抽题（可指定题数）、按知识点练习、重做上轮错题、题库概览
- 答错的题自动进入错题本，下一轮可专门重做
- 本轮结束输出：总正确率、各知识点命中率、错题回顾（含正确答案与解析）
- 答题中输入 `q` 随时结束本轮；直接回车表示看答案
- 输入全部按行读取（`fgets`），不使用 `scanf`，输错不会死循环

## 示例

```
[1/3] 知识点：预处理
----------------------------------------
下面程序的输出是什么？
    #define SQ(x) x * x
    printf("%d\n", SQ(1 + 2));

（填整数结果，直接回车看答案）

答案> 9
✗ 错误，正确答案：5
  解析：宏是纯文本替换：SQ(1 + 2) 展开为 1 + 2 * 1 + 2，按优先级算出 5，不是 9。
  正确写法是 #define SQ(x) ((x) * (x))。
```

## 加题

题库是 `cdrill.c` 里的一个静态数组，按知识点分组。追加一条 `MC(...)` 或 `NUM(...)` 即可，知识点会自动出现在菜单里：

```c
NUM("控制流",
    "下面程序的输出是什么？\n"
    "    int i = 0;\n"
    "    while (i++ < 3)\n"
    "        ;\n"
    "    printf(\"%d\\n\", i);",
    4,
    "后置自增在比较之后才生效，最后一次比较后 i 变成 4。"),
```

数组元素上限是 `MAX_Q`（当前 64），超过时改大它。

## 答案怎么保证是对的

41 道题的正确答案不是估的：每条题面代码都写成独立的 `.c` 片段，用 `clang -std=c11` 在本机实际编译运行，逐条比对输出。程序本身另做了两项验证：

- `-Wall -Wextra -Wpedantic` 零警告
- AddressSanitizer + UndefinedBehaviorSanitizer 下跑完全部题目和边界输入（超长行、超范围数字、非法菜单项）无报错
